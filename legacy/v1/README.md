# Archived original implementation

This directory preserves the initial public repository implementation before the v2.0.1 publication update. It retains its original regional confidence weighting and fitting/reporting behavior for historical reference. It is not the current application entry point.

For the current English application, run `ce3d_xps_fitter_gui.py` from the repository root. The current default is Gaussian-convolved LA-type peaks, a fixed Shirley background and 8000-step MCMC, without regional confidence weighting. See the root README and release notes.

`README_original.md` reproduces the earlier repository instructions unchanged. Historical software is provided as-is; the main tests and publication validation concern the current release.
